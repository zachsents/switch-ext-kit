# switch-ext-hello

What it is, in a line.

A [Switch](https://switch.ax) extension, built on [switch-ext-kit](https://github.com/zachsents/switch-ext-kit).

## Install

Ask Switch's agent to install `github:OWNER/switch-ext-hello`, or add it in the desktop's Extensions view
(⌘K, Extensions).

## Develop

```sh
bun install
bun run check
bun start   # serves MCP on stdio
```
